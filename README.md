# 西安电子科技大学本科毕业论文 LaTeX 模板

本目录提供本科毕业论文的精简示例，包含封面信息、中英文摘要、章节、公式、图片、表格、参考文献和致谢。填写个人信息并替换示例内容后使用。

## 编译与使用

安装包含 XeLaTeX、Biber、latexmk 和中文字体的 TeX Live 等 TeX 发行版，在本目录运行：

```powershell
latexmk -xelatex main.tex
```

也可依次运行 `xelatex main.tex`、`biber main`、`xelatex main.tex`、`xelatex main.tex`。输出文件为 `main.pdf`。若缺少字体或宏包，请按报错安装。

- `main.tex`：填写题目、姓名、班级、学号、导师等封面信息和关键词。
- `chapters/`：填写中英文摘要、章节与致谢；可根据需要增加章节并在 `main.tex` 中引用。
- `tables/`、`figures/`：存放自制表格和图片；正文中的 `example-image` 是 TeX 发行版提供的示意图，需替换。
- `references.bib`：替换为自己的参考文献数据。
- `.latexmkrc`、`xduugthesis.cls`、`xdulogo.pdf`：分别提供编译配置、论文格式和校徽。

## 论文格式检查

以下是整理自 22 级本科生毕业设计归档经验的提醒，供检查时参考，不代表学校现行统一规定。不同学院、专业、年份或导师可能有不同要求，请以当年正式通知及导师意见为准。

- 封面：右上角班级和学号的标签应对齐，填写内容在横线上居中；题目中的英文建议使用 Times New Roman。提交的正文前应包含论文封面。
- 英文摘要：检查表达是否准确、通顺，以及英文关键词之间的间距。
- 目录：检查目录内容和页码，目录中的标题不出现英文缩写；同时核对各级标题与正文之间的间距。
- 公式：逐一检查公式的含义、符号、编号及引用是否正确。
- 正文：检查是否有不应出现的加粗内容，以及标题后、段落前后的间距；具体标题格式仍以正式要求为准。
- 图表与分页：图片和图中文字应足够清晰，适合打印阅读；检查图片之间的距离和页面留白，避免图过小、图与图紧挨或单页留白过多。引用他人图片时注意标注来源。
- 总结与展望：可将工作总结、不足与局限、未来展望分开撰写。
- 参考文献：可将约 50 条作为经验参考，具体数量及来源质量以学院和导师要求为准。
- 答辩：提前熟悉论文内容和格式；有答辩环节不允许看讲稿，老师也可能侧重论文而非 PPT，请以答辩现场要求为准。

## 归档材料检查

以下补充说明中的《安排》指“22级本科生毕业设计（论文）系统归档材料说明及时间填写安排”。本目录未附该文件，任务书、中期检查表等请结合原文件核对，尤其是日期与签字要求。

1. **论文封面**：按上文检查班级、学号及英文题目的字体和对齐方式。
2. **诚信说明书**：第一段缩进；校内、校外指导教师签字日期按《安排》统一。
3. **任务书**：按《安排》填写。
4. **工作计划书**：表格上方信息使用小三号或四号，表格下方信息使用小四号，间距建议 1.5 倍；具体以学院要求为准。
5. **开题报告**：封面表格信息需手动居中对齐。
6. **中期报告**：表格信息使用粗体；题目需要两行时，可在题目表格下方增加一行。
7. **中期检查表**：按《安排》填写，并检查标题字体样式。
8. **成绩登记表**：收到登记表后，在原始电子版填好指导教师和评阅人意见并转为 PDF，再将扫描版中的答辩小组意见截图放到对应位置；具体操作以学院要求为准。
9. **论文正文**：正文前附一份封面。
10. **外文资料翻译**：封面参照论文封面的对齐要求；外文文献题目保留英文，无需翻译为中文。
11. **指导情况登记表**：按当年学院通知填写；目前没有收到额外格式说明。

除开题报告封面外，其他归档材料的标题按该经验使用宋体二号粗体；这条提醒针对归档材料标题，与正文不应随意加粗的检查分开。WPS 打开 Word 材料时可能出现格式差异，建议使用 Microsoft Word 核对。

## 2026 届生科院毕业设计时间线参考

以下根据西电生命科学技术学院 2022 级本科生的经历整理，时间为大致阶段，供后续同学规划参考，不是后续年份的日程或统一规定。具体截止时间、材料和答辩形式请以当年学校、学院、系统通知及导师要求为准。

1. **开题（11 月初至 12 月底）**：11 月初开始选题；校外毕设需与校外指导教师确定题目。按要求上传任务书和工作计划书，并在 12 月底前提交开题报告。填写材料和时间时应核对真实情况及当年安排。
2. **中期答辩（3 月中旬）**：建议提前完成约一半工作量，便于后续推进。该届生科院要求线下答辩，其他学院可能不同。如需更换题目，按要求填写申请表，并在系统中核对变更结果。
3. **盲审准备与提交（3 月底至 5 月初）**：建议尽量在 5 月前完成实验，并在五一假期结束后基本完成论文。该届经验中，校盲审涉及论文主体、查重和格式检测；查重文件不含封面，院盲审材料基本类似并按学院通知发送。盲审附件需按盲审要求隐去个人信息。
4. **盲审意见修改（5 月中旬）**：收到意见后逐项核对并修改，按通知提交修改材料。
5. **毕业答辩（6 月初）**：根据当年通知准备答辩和后续归档材料。

该届一次系统提交的经验：论文模块提交从摘要到参考文献的主体部分；附件提交盲审要求的 11 项材料，系统归档附件无需隐去个人信息。这与**送审材料的匿名要求**是不同环节，不能互相替代。论文主体、查重、送审及归档文件的封面、致谢、匿名和附件范围均可能因环节变化，提交前必须逐项核对当次通知。
